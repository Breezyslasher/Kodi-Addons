# t1m Library Routines

Shared support routines for [t1m's](https://github.com/learningit) Kodi video
addons — directory building, library `.strm` export, TV listings and playback
helpers.

This is a dependency module, not something to install on its own. It is carried
in this repository because [TubiTV](../plugin.video.tubitv/) needs it.

The code is upstream's, unmodified apart from a malformed `<source>` tag in
`addon.xml`; the version is left at upstream's `4.0.9` so it stays
interchangeable with the copy in any other repository.

- Upstream: https://github.com/learningit/repo-scripts
- Forum: https://forum.kodi.tv/showthread.php?tid=247163
